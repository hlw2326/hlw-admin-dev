使用 支付宝开放平台

基于支付宝 OpenAPI 标准接口，全面支持电脑网站支付、手机网站支付、App 支付及当面付扫码

支付宝开放平台创建的自研应用 AppID

使用支付宝开发助手生成的 PKCS8 或 PKCS1 格式商户私钥内容

在开放平台应用开发设置中获取的“支付宝公钥”（用于异步通知验签）
