使用 微信支付商户平台 (V3 API)

基于微信支付最新 V3 标准 API 接口，全面支持 Native 扫码、JSAPI 公众号/小程序、H5 手机网页与 App 支付

微信支付分配的 10 位商户号 (MCHID)

关联微信公众号或小程序的 AppID

在 [ 微信商户平台 > 账户中心 > API安全 ] 中设置的 32 位 APIv3 密钥

在商户平台下载的证书序列号，若下方已配置商户公钥证书则可留空自动识别

在商户平台申请证书时生成的 `apiclient_key.pem` 私钥文本内容

商户 API 证书 `apiclient_cert.pem` 文本内容（配置后系统自动解析证书序列号）

微信支付公钥或平台证书文本。留空时系统将通过接口自动下载

全局默认异步通知回调地址，订单未指定时将使用此地址
